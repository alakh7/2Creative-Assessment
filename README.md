# Contact Search App

## Overview
This is a **Contact Search Application** built using **Next.js, TypeScript, and Framer Motion**. It allows users to search for contacts based on multiple parameters like name, email, phone number, city, state, and more. The results are displayed in a **tabular format** with pagination for better usability.

## Features
- **Search Functionality**: Users can search contacts using multiple criteria.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- **Pagination**: Displays search results with navigation controls.
- **Animated UI**: Smooth animations using Framer Motion.
- **Dummy Data**: Uses mock contacts for demonstration.
- **Reset Search**: Users can reset filters with a single click.

## Technologies Used
- **Next.js** (React framework for SSR & SSG)
- **TypeScript** (for type safety)
- **Framer Motion** (for animations)
- **Tailwind CSS** (for styling)
